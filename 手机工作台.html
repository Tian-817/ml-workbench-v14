  • 平台政策与费率 · 墨西哥佣金改「类目分级」主流12%-18%、低于499比索低价单另收5比索固定费、4/22起 Classic 最多降2.5个点 / Premium 最多降5个点、物流计费改「实重与体积重取高」长×宽×高÷6000（妙手ERP / 赛狐ERP）：2026 年墨西哥站取消了原来那条17.5%固定佣金，改成按「站点+类目+刊登模式」三个变量分别定价，主流区间12%-18%，部分消费电子低到14.5%。低于 499 MXN 的订单每单再收5比索固定佣金，做低价铺货的单量越大被吃掉越多。4月22日那轮下调后，Classic 和 Premium 的佣金差从4.5%压到1%——Premium 多花1%换来免息分期权益和搜索权重倾斜，高客单价品反而划算。物流这条最容易漏：自发货从「只看实重」改成「实重与体积重取大值」，体积重=长×宽×高÷6000，收纳盒/抱枕/毛绒/灯具这类轻泡货运费直接被拉一截，定价公式里不把体积重算进去，上架后实扣会比估算高一截。四层成本（类目佣金+固定成交费+支付费约3.99%+物流费）是平行相加、不是链式相乘，定价先用净额倒推法。西语：comisión / costo fijo / peso volumétrico。妙手ERP / 赛狐ERP 2026
  • 物流履约与税务合规 · RFC 是墨西哥的利润分水岭：无RFC每单预扣36%（16% IVA + 20% ISR），本土RFC绑定本地账户降到10.5%最优档，6月起主体一致性验证堵死挂靠，纯直邮自发货暂时不用办（大数跨境 / Ushop / 10100 / ESG跨境）：同一笔销售额，有本土RFC+本地账户预扣10.5%、没RFC预扣36%，到手差一大截，而且从第一笔订单就扣、没有缓冲期——36%是20%所得税加16%增值税并行按销售额算，跟你的采购成本、毛利薄厚无关。四档税率记清：无RFC 36%；离岸RFC 16%（免所得税）；本土RFC+境外账户 18.5%；本土RFC+墨西哥本地账户 10.5%（最优）。6月启动的 RFC 主体一致性验证要求店铺主体=RFC持有人、银行账户持有人名称也得一致，挂靠租号一旦核验失败直接拉到36%、SAT追溯5年还会连带封店。对甜甜的 me2 直邮自发货：平台只代扣清关环节税费、不触发36%预扣，所以纯直邮阶段可以暂缓办RFC、优先把物流和选品跑顺；但如果以后要发FULL仓/海外仓，必须提前3-6个月启动RFC申请，货到仓再补税号就来不及。NOM认证（电子/电器类）也要留意。西语：RFC / retención / IVA / ISR。大数跨境10100 / Ushop / 企财盈 / ESG跨境 2026
  • 商品管理与数据化选品 · 平台后台数据薄弱，靠关键词数据库做「类目词/长尾词/竞品词」双向反查，输出高潜力低竞争长尾词清单直接用于标题和广告，再用精细化利润计算器剔除亏损SKU（蓝鲸BI / 妙手ERP）：美客多原生后台数据能力弱，卖家搭 Listing、投广告全凭主观选词，CPC 一直涨转化却跟不上。数据化选品的做法：①关键词数据库双向反查——看每个西语词的搜索热度、转化商品、广告竞价、竞争度，还能区分自然流量词和付费广告词，挑「搜索量在涨、平台相关商品少」的供需缺口词；②周期热度追踪——提前布局节日/旺季流量词，别等词热了才跟进（墨西哥买家用的西语搜索词和英语市场完全不同，直接翻译英语词会漏掉真实需求）；③行业趋势模块看全类目市场容量、淡旺季周期、价格带分布、品牌份额，自动标低竞争高增速蓝海；④精细化利润计算器把采购、头程、尾程、平台费全录进去，测算不同售价下的净利/毛利率/ROI、模拟折扣满减，上架前先剔除亏损SKU。给甜甜的落地提醒：长尾词3-4词带场景/人群修饰、避开1-2词大词红海，词做14天回收窗避免两周内重复，蓝海只留纯机械/纯工具/纯收纳轻小件。西语：palabra clave / nicho / margen / ROI。蓝鲸BI / 妙手ERP 2026

💡 今日干货

「2026 墨西哥税费三道坎 + 轻小件保利润」打法：

  • 先合规省税：尽早注册 RFC（境外或本地），把综合税负从惩罚 69.5% 压到离岸 16% 甚至本土+本地 10.5%；无 RFC 每笔直接吞掉大半利润，且平台可能限制上架。
  • 到岸成本先加 33.5%：中国自发货小包（非 USMCA 原产）清关统一 33.5% flat rate，另有 1463 税号对华加征 5–50% 永久关税、6/1 起强制 MVE 电子价报单严查低报；定价时把它算进 CIF，别用旧「50 美元免税」思维。
  • 净收益反推售价：美客多墨站已上线 Net proceeds 净收益定价，你只设想赚多少，系统反算佣金+预估运费出最终价；但头程/提现/仓储/33.5% 关税/退货损耗仍需自己补进成本。
  • 免运门槛当转化开关：把轻小件凑到约 MXN$299 免运线附近，挂「Envío gratis」标签显著提升曝光；主力款卡 MXN$150-600（约 8-33 美元）落中国轻小件红利带。
  • 标题前 40 字符：西语核心词前置（如「bote basura cocina」「ciclocomputadora bicicleta」），属性字段填满 10-20 个，算法把完整度当排名信号；Buen Fin 埋「oferta」「envío gratis」大促词。
  • 红线不碰：RFC 税号是清关与开票前提，新店尽早补齐；禁售服装/婴儿/刀具/食品/药品/3C/实木/压力容器/易燃/二手/种子/古董/纹身，IP 硬拒。
